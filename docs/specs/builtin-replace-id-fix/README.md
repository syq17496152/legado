# builtin-replace-id-fix — 内置替换净化规则 id 修复

## 状态：开发中

## 功能概述

F7/4.10 引入的内置替换净化规则使用负数 id（-1~-12），与编辑页「新建」哨兵值 -1 及 `id > 0` 查库判断冲突，导致点击编辑显示空数据。本变更将内置规则 id 迁移为正数段 1~12，并为已装设备提供一次性数据迁移（保留用户对内置规则的修改）。

## 核心能力

| 能力 | 说明 |
|------|------|
| 正数 id | 内置规则 id 改为 1~12，远离用户 timestamp 级 id，编辑页判断恢复生效 |
| 存量迁移 | 已装设备升级后自动把 DB 中负 id 行换 id 保留（内容不重置），删除负 id 行 |
| 幂等导入 | 新装/重复运行均安全：无负 id 行走 `insertIfAbsent`，已有新 id 行不覆盖 |
