## cronet版本: 149.0.7827.201

**2026/07/08**
- 书源/订阅源管理界面深度重构，对齐书架两维度独立架构：分组样式（列表平铺/按类型/按分组）与视图模式（列表/紧凑列表/网格二至六列）彻底解耦为独立配置；新增排序功能（名称/启用/类型/分组/地址，支持升降序，与原手动/权重/更新时间等菜单排序兼容）；进入分组/类型文件夹后支持返回键回到根目录
- 修复书源/订阅源搜索框反模式：筛选类型/分组不再回填 type:/group: 到搜索框，改为隐藏字段传给后端，搜索框回归纯名称搜索；进入子目录后搜索框仍可正常按名称过滤
- 默认主题改为「暗夜紫」夜间主题：新用户首次安装即进入夜间模式并使用暗夜紫配色，老用户主题设置不受影响
- 精简书源/订阅源/发现/RSS页面工具栏：所有功能图标统一收进右上角三点菜单，工具栏仅保留三点按钮，更简约统一
- 优化书源/订阅源文件夹视图：新增配置对话框（分组样式/视图/间距），文件夹卡片改为书架风格的首字+主题色设计，支持动态间距与列数；三点菜单统一入口
- 修复书源/订阅源"按类型"文件夹归类不生效：选择"按类型"后文件夹视图现正确按源类型字段归类展示（书源：文本/音频/图片/文件/视频；订阅源：网页/图片/视频），点击类型文件夹可筛选对应类型源；菜单"类型"子菜单选项现也可正常筛选
- 优化欢迎页自定义：新增"替换欢迎页"默认开启开关，选择图片后自动按屏幕比例居中裁剪，避免变形；.9.png 和 GIF 自动跳过裁剪
- 简化自动任务 Cron 输入：改为"每天/每小时/自定义"三选一选择器，自定义档才显示 Cron 表达式输入框
- 优化视频倍速选择列表：倍速面板改为靠右垂直居中的圆角卡片样式，不再占满全屏；当前倍速以主题色高亮显示；倍速值分组显示（极速区与常用区之间加分隔线）；倍速文本格式优化（1x、15x、1.25x，去除冗余小数）
- 调整调试工具入口：从"我的"页面迁移至"设置→其他设置→调试工具"，精简主入口
- 视频播放新增「边下边播」开关：默认关闭（因代理缓存对部分带 header/m3u8 视频不兼容会导致无法播放），可在视频设置中手动开启以边下边播缓存分片、省流量、弱网拖动秒切
- 阅读源列表页改为缓存优先加载：进入订阅源文章列表时优先显示本地缓存（增量更新无闪烁），同时后台请求网络数据；WebView 阅读页默认缓存优先，二次进入秒开
- 视频播放器新增默认静音 + 高倍速支持：视频播放默认关闭声音（可在播放界面一键开启或视频设置中关闭默认静音）；倍速选择新增 5X/10X/15X 高倍速档位
- 修复视频播放器多项回归问题：订阅源边下边播不生效（3处订阅源分支未启用缓存）、默认静音仅图标无实际效果（onPrepared 未调用 setNeedMute）、非全屏模式缺少倍速按钮、播放中切换倍速不生效（setSpeedPlaying 空实现）、缓冲进度条不显示（getBufferedPercentage 恒返回 -1）
- 修复视频倍速UI优化导致的播放回归：边下边播默认值由开启改为关闭，避免 ProxyCacheManager 代理缓存对带 header/m3u8 特殊视频不兼容造成无法播放
- 修复书源/订阅源管理「类型」菜单图标缺失：补齐类型筛选菜单图标，与文件夹配置/排序/分组等其他菜单项视觉对齐
- 优化书源/订阅源文件夹卡片样式：复用书架默认封面图作为文件夹封面背景，替换原先的纯色渐变大色块+首字占位
- 改进开发测试基础设施：E2E 自动化测试框架支持真机端到端自动验证（UI 执行器滚动查找/自愈/失败跳过/证据收集加固），测试用例对齐 Compose UI 实际实现，提升功能交付质量保障

**2026/07/07**
- 修复 Cronet 149 网络功能崩溃问题：根因是项目 download.gradle 漏下载了 httpengine_native_provider_java.jar（Cronet 149 新增的独立 jar，包含 HttpEngineNativeProvider 等适配 Android 11+ 系统内置 HttpEngine 的类），缺失导致 JavaCronetProvider 在 Android 11+ 系统触发 NoClassDefFoundError；现已补全下载并升级回 149
- 优化书源调试主线程流畅度：书源调试/规则执行时改为先读内存缓存再查数据库，减少主线程阻塞，二次访问同书源时显著提升响应速度
- 优化 RSS 阅读/源编辑预览加载速度：WebView 拦截主资源请求时改用同步 OkHttp 调用，省去协程调度开销，减少主线程阻塞时间
- 优化 APK 体积：仅保留项目已翻译语言（中/英/西/日/葡/越），移除第三方库自带的其他语言资源
- 新增书源/订阅源文件夹视图：发现页、订阅源页、书源管理、订阅源管理均支持文件夹/列表视图切换，视图模式自动记忆；点击文件夹仅临时进入分组列表，不改变默认视图偏好（再次进入仍是文件夹模式）；文件夹卡片参考书架样式优化，采用主题色背景+渐变标题
- 修复长时间使用后内存占用持续增长的问题：图片加载失败 URL 缓存、规则解析缓存改为 LRU 自动淘汰（上限 200/64）；删除书源/订阅源时同步清理并发限流记录
- 新增自动任务系统：支持 cron 表达式定时执行 JS 脚本，可自动刷新书籍目录、通知新书更新等；在「我的」页面可开关自动任务服务并进入任务管理页面，支持任务的增删改、批量设置 Cron、导入导出、拖拽排序、日志查看
- 新增高亮规则系统：阅读时支持正则/字面量匹配自动高亮，9 通道样式（背景色/文字色/加粗/斜体/下划线/删除线/方框/着重号/自定义字体），在阅读界面菜单可进入规则管理页
- 新增手动划线高亮：阅读时长按文字可选中并添加高亮，支持编辑备注，目录页新增「标注」Tab 查看书内所有高亮
- 新增高亮规则分组管理：支持新建/重命名/删除分组，规则可按分组归类，分组内规则可导出为 JSON 复制到剪贴板
- 新增预设规则库：内置 12 条常用高亮规则（对话/书名号/括号标注/标题强调/心理活动/旁白/重点/诗词/省略/数字/英文/日期），可一键添加到当前列表
- 新增高亮规则导入导出：支持通过剪贴板 JSON 格式批量导入导出规则，方便在设备间迁移配置
- 新增调试日志悬浮球：在「其他设置」开启后，屏幕右下角显示悬浮球，点击可快速查看应用日志，日志支持按级别（错误/警告/信息/调试）过滤显示

- 优化大 Cookie 站点登录态保持：Cookie 超长截断时优先删除统计类 Cookie（如 _ga/_gid 等），避免误删登录态 Cookie 导致登录失效
- 修复代理客户端缓存无限增长导致内存泄漏：改为 LRU 缓存（上限 20），长跑后自动淘汰最久未使用的代理客户端
