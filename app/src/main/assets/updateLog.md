# 更新日志

## cronet版本: 500.0.1

**2026/09/13**
### 新增
- 内置视频播放器支持投屏到电视/投影/机顶盒：播放器的三点菜单新增「投屏」，自动搜索同一 Wi-Fi 下的可用设备（电视上设置的名称会直接显示），选中后手机就变成遥控器——可暂停/继续、拖动进度、调节音量，也能随时一键结束投屏
- 带防盗链的视频也能投：部分站点的播放地址必须携带来源信息才能取流，而电视自己带不了这些信息，此前投上去只会黑屏；现在投屏时会由手机代为取流再送给电视，这类视频可以正常播放
- 投屏成功后手机自动暂停播放，避免手机与电视同时出声、重复消耗流量；结束投屏后会提示可继续在手机上看
- 投屏中播放页顶部常驻显示「正在投屏：设备名」状态条，点击可随时回到投屏面板
- 投屏中切换集数/线路/上一部下一部会先自动结束投屏并回到投屏面板，避免手机与电视各播各的
- 已下载到本地的视频同样支持投屏
- 记住上次投过的设备，下次打开投屏面板一点即投
- 视频播放器设置新增「投屏」分组：可关闭投屏入口，也可在直连失败时临时开启「强制走代理」用于排查
### 说明
- 投屏期间保持 Wi-Fi 连接不中断，锁屏或切到后台都不影响播放；通知栏常驻控制入口，随时可暂停或结束
- 电视对格式的支持各有差异：直播类视频（HLS）在部分电视上可能没有画面，遇到时可改用其他方式播放
- 投屏需要在同一 Wi-Fi 内使用；手机使用移动数据时无法搜索到设备

**2026/09/12**
### 修复
- 修复应用内检查更新误报"获取新版本出错"的问题：备用更新源通道失效时，"已是最新版本"会被误当作错误继续查询并报错；现确认无更新即静默，仅两处更新源都查询失败才提示
- 修复更新包匹配错乱的问题：更新包文件名的解析与包类型识别未对齐实际发布命名，导致测试包/共存包永远查不到自己的更新、正式包会误把测试包当作更新目标；现按测试/正式/共存三种包型正确匹配各自的更新包与版本号
- 修复统一搜索点击文章进详情页必闪退的问题，详情页可正常打开并显示多源列表；「AI 图库」「AI 图片供应商编辑」两个页面的同类隐患一并消除
- 修复部分站点视频在浏览器能播、内置播放器黑屏或失败的问题：此类站点的播放链接带有实效性签名，此前会被误拆导致签名丢失、被服务器拒绝，现已完整保留签名链接直接播放

- 修复内置替换净化规则点击编辑后显示空数据的问题；已安装用户升级后自动迁移原有内置规则，此前对这些规则的修改（开关状态、规则内容）完整保留，覆盖安装场景也能完成迁移
### 优化
- 订阅源「自由」布局的诊断日志大幅精简：滚动浏览时的逐帧日志改为按时间窗合并输出，日志文件不再被单一功能刷满；排查异常的关键日志保留，需要完整逐帧日志时可在后台开关恢复

- 清理全仓散落的调试日志与重复日志：高频失败路径（域名解析重试、证书错误等）统一按时间窗合并输出，日志列表不再被同一错误刷屏；图片加载失败不再输出完整链接
### 修复
- 修复「自由」样式滑动或加载更多时闪退的问题
- 修复「自由」样式上滑到底不自动加载下一页的问题
- 修复设置背景图后部分弹窗整体变透明只剩内容悬空的问题（页码选择、设置页各类选择/输入弹窗、取色器等）；弹窗底色圆角与全局基线对齐
