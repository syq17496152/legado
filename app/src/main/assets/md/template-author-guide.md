# 阅读页模板 · 作者指南

> 本指南随应用离线内置（工作台内打开即可），描述**模板文档的结构约定、样式基线、素材与合规红线**。
> 上手最快的方式：管理页 →「添加模板」→「从内置模板复制…」得到一份可编辑副本，再按本指南改。

---

## 一、模板能改什么、作用在哪

- 模板决定**阅读页的文档外观**：页眉/页脚、开篇版式、正文容器样式、装饰图形与动效。
- 当前版本作用范围：**本地 Markdown 阅读**（在线正文 / 本地 txt 随文本渲染模式一并开放；**出版 EPUB 不适用**）。
- 关闭整体开关后，阅读页**完全回到原有排版**（等同没有模板系统，无残留）。

## 二、文档结构（`readerTemplate.json`）

| 字段 | 说明 |
|------|------|
| `schemaVersion` | 当前为 `2`（`1` 导入时会自动升级） |
| `type` | `paged`（分页）或 `scroll`（滚动） |
| `name` / `description` | 列表展示用；名称必填 |
| `firstPageHtml` | **开篇页**结构（可满载装饰：题图、大标题） |
| `otherPageHtml` | **续页**结构（常态：窄页眉 + 正文 + 页脚） |
| `scrollHtml` | 滚动模板的**唯一**结构（`type=scroll` 时必填） |
| `css` | 样式（含日/夜双版与素材，见下） |
| `javascript` | 可选；运行在**沙箱 iframe** 内，不能访问宿主对象 |

### 两条硬约定（写错会静默失效）

1. **正文槽位**：结构里必须有且只有一个 `data-reader-flow="body"` 的元素 —— 正文会被注入到这里。
   **正文元素必须留在该槽位子树内**，装饰请放在槽位之外。
2. **滚动模板**：必须有且只有一个 `data-reader-scroll-viewport`（滚动画框）；且外壳用**视口单位**（如 `100vh`）定高 ——
   用 `height:100%` 会在根壳（普通流容器）里塌成内容高，表现为"页数恒 1、翻不动"。

## 三、可用字段槽位

在任意元素上写 `data-reader-field="<字段名>"`，运行时会填入真值：

| 字段 | 含义 |
|------|------|
| `bookName` | 书名 |
| `chapterTitle` | 章节名 |
| `progress` | 阅读进度百分比 |
| `page` / `pageCount` | 当前页 / 总页数（**沙箱派生**） |
| `percent` | `progress` 的别名 |
| `time` | 当前时间（分钟级刷新） |
| `battery` | 电量文本（取不到时**保持占位，不写假值**） |

> 未列入的字段名会被忽略（不报错）。宿主提供的值优先于沙箱派生值。

## 四、样式基线

- **日/夜双版必须都写**：`:root` 为日间基线，`[data-reader-theme="night"]` 覆盖夜景；
  只写一侧会导致另一种主题下**读不清**。
- **字号与行高由宿主下发**：正文请消费 `--md-font-size` 与 `--md-line-height`（用户设置才能生效）。
- **装饰不得挤占正文**：页眉/页脚各 ≤ **15%** 视口高；装饰区与正文安全区**不相交**（续页尤其）；
  装饰变化**不得改变正文测量**（否则翻页页数会变）。
- **装饰强度由用户设置优先**：运行时会按"无/轻/中/强"下发 `--rp-decor-scale` 并以 `!important` 控制
  装饰透明度 ⇒ 作者 CSS 里的低不透明度**会被覆盖**（低调观感请把 alpha 做进素材本身）。
- **动效克制**：声明了动效就必须给 `@media (prefers-reduced-motion: reduce)` 静默分支；
  建议元素 ≤ 120、动画声明 ≤ 12。

## 五、素材与合规

- **离线优先**：素材随模板走。图片/字体请用**内联 `data:`** 或随包 `assets/`；
  **不得**引用 `http(s)` 外链、`@import`、`fetch`/`XMLHttpRequest`（导入时会拒收或降级）。
- **字体**：仅限 **OFL** 等允许再分发的许可，且**许可原文随包**。
- **图片**：仅限**自研**、**CC0 / 公有领域（PD）**；每图登记来源与许可（`sources.json`）。
- **禁区**：不得内置第三方 IP 原作素材（动漫/游戏/影视衍生图案、角色、Logo 等）。
  第三方风格请**仅限本人导入后在本地使用**，导出再分发的授权风险由你自行承担。
- 单条内联素材上限 8 MB、总量上限 64 MB；超大 `css`（>320 KB）会提示编辑时需分块加载。

## 六、创作流程

1. **添加**：管理页 →「添加模板」→「从内置模板复制…」（或「导入模板 JSON」）。
2. **编辑**：行操作 ⋮ →「编辑」→ 选择字段（HTML / CSS）→ 保存（支持大文本，落库无 Binder 上限问题）。
3. **预览**：行操作 ⋮ →「预览」→ 弹窗内走**正式渲染链路**（所见即所得），可翻页核对。
4. **应用**：点「应用」；或用「跟随主题」交给日夜自动切换。
5. **导出 / 分享**：行操作 ⋮ →「导出 JSON」；导出前会提示素材授权风险。
6. **导入他人模板**：管理页 →「添加模板」→「导入模板 JSON」；导入前会提示"仅限本地使用、不得分发"。

## 七、排错速查

| 现象 | 多半原因 |
|------|---------|
| 模板渲染了但**页数恒 1** | 缺 `data-reader-scroll-viewport`（滚动）或正文槽位写错 / 文档只有一个 `body` 槽位被装饰覆盖 |
| 页脚页码/时间**恒空** | 槽位名拼错（须为 `page` / `time`），或未写在文档里 |
| 夜间**看不清正文** | 只写了 `:root`、缺 `[data-reader-theme="night"]` 覆盖 |
| 翻页**错位 / 跳回首页** | 用绝对定位把正文挪出了正文流；正文必须留在 `data-reader-flow="body"` 子树内 |
| 导入被拒 | 含外链 / 素材超限 / 结构非法（导入报告会给出逐条原因） |
