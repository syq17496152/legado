# 定时任务帮助

定时任务由五字段 Cron 驱动，按计划执行同步 JavaScript。脚本环境与书源规则一致，并复用登录、Cookie 与缓存能力。脚本的最终返回值会按返回协议解析为更新目录或发送通知等动作。

## Cron 表达式

格式为 `分 时 日 月 周`，使用空格分隔，按设备本地时区运行，最小粒度为一分钟。

| 表达式 | 说明 |
|--------|------|
| `*/5 * * * *` | 每 5 分钟 |
| `0 9 * * *` | 每天 09:00 |
| `0 9 * * 1` | 每周一 09:00 |
| `0 0 1 * *` | 每月 1 日 00:00 |
| `0 8,20 * * *` | 每天 08:00 和 20:00 |
| `*/30 6-23 * * *` | 06:00 至 23:00 之间每 30 分钟 |

可使用的符号：

- `*` 表示任意值，`?` 与 `*` 相同
- `,` 表示多个值
- `-` 表示范围
- `/` 表示步长

取值范围：分 `0-59`，时 `0-23`，日 `1-31`，月 `1-12`，周 `0-7`，其中周日可写 `0` 或 `7`。

日与周同时受限时按 OR 匹配。例如 `30 9 1-7 * 1` 会匹配每月 1 至 7 日的 09:30，以及每个周一的 09:30。

## 返回协议

脚本可以返回动作数组：

```json
[
  { "type": "refreshToc", "bookUrl": "https://..." },
  { "type": "notify", "title": "完成", "content": "全部更新完毕" }
]
```

也可以返回单个动作对象：

```json
{ "type": "notify", "title": "签到", "content": "已签到 {time}" }
```

或将动作数组放在 `actions` 字段中：

```json
{
  "actions": [
    { "type": "refreshToc", "bookUrl": "https://..." }
  ]
}
```

返回 `null` 或无法解析的结果时视为没有动作。

## 更新书籍目录

`refreshToc` 按 `bookUrl` 精确查找书架中的书籍并刷新目录，可选发送更新通知或缓存新章节。

```json
{
  "type": "refreshToc",
  "bookUrl": "https://example.com/book/123",
  "notify": {
    "enable": true,
    "minCount": 1,
    "title": "《{book}》更新了",
    "content": "新增 {newCount} 章\n最新：{chapter}\n时间：{time}"
  },
  "cache": {
    "enable": true
  }
}
```

通知文案支持 `{book}`、`{author}`、`{newCount}`、`{chapter}` 和 `{time}` 占位符。没有新增章节时不会发送通知。

## 发送通知

```json
{
  "type": "notify",
  "title": "每日签到",
  "content": "已完成\n时间：{time}",
  "level": "high",
  "id": 1
}
```

`level` 可使用 `high`、`error`、`fail`、`failed` 或 `low`；相同 `id` 的通知会互相替换。通知文案支持 `{task}` 和 `{time}` 占位符。

## 任务字段

编辑页可以配置名称、启用状态、Cron、脚本和备注，以及请求头、JavaScript 库、并发率、登录 URL、登录 UI、登录检查脚本和 CookieJar。脚本可直接填写 JavaScript，也兼容外层 `@js:` 或 `<js>...</js>` 包裹。

上次运行时间、执行结果、错误和日志由应用维护，导入时不需要填写。定时任务总开关开启后，已启用的任务才会按 Cron 自动执行。
