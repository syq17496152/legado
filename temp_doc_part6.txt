## 6 ViewModel 处理流程

### 6.1 通用 ViewModel 模式

所有 ImportViewModel 继承 BaseViewModel，具有统一结构：

    val errorLiveData = MutableLiveData<String>()
    val successLiveData = MutableLiveData<Int>()
    val allSources = arrayListOf<T>()       // 解析后的全部实体
    val checkSources = arrayListOf<T?>()     // 本地已有的对应实体
    val selectStatus = arrayListOf<Boolean>() // 选中状态

### 6.2 通用 importSource 流程

    importSource(text: String)
    +-- text.isJsonObject()
    |   +-- BookSource: 尝试解析 $.sourceUrls 列表(批量URL) -> 逐个 importSourceUrl()
    |   |             -> 失败则按单个对象解析
    |   +-- 其他: 按单个对象解析
    +-- text.isJsonArray() -> 按数组解析
    +-- text.isAbsUrl() -> importSourceUrl() -> HTTP下载 -> 递归解析
    +-- text.isUri() -> uri.readText() -> 递归 importSourceAwait()
    +-- 其他 -> 抛异常 "格式不对"
    -> comparisonSource() -> 与本地对比 -> successLiveData

### 6.3 importSourceUrl 网络请求

所有 ViewModel 的 URL 请求遵循统一模式：

    okHttpClient.newCallResponseBody {
        if (url.endsWith("#requestWithoutUA")) {
            url(url.substringBeforeLast("#requestWithoutUA"))
            header(AppConst.UA_NAME, "null")
        } else {
            url(url)
        }
    }.decompressed()  // 支持gzip等压缩

**#requestWithoutUA 约定**：URL 以 #requestWithoutUA 结尾时，去掉该后缀并将 UA 头设为 "null"，用于某些禁止非浏览器 UA 访问的站点。

### 6.4 RuleUpdate 缓存

BookSource 和 RssSource 的 importSourceUrl 支持缓存优先：

    RuleUpdate.cacheBookSourceMap[url]?.also {
        allSources.addAll(it)
        RuleUpdate.cacheBookSourceMap.remove(url)
        return
    }

命中缓存则跳过网络请求。此缓存来自 RuleUpdate（规则更新检查模块）。

### 6.5 ImportBookSourceViewModel（最完整实现）

源码：ImportBookSourceViewModel.kt

额外字段（其他 ViewModel 不具备）：
- 
ewSourceStatus：标记每条是否为新增
- updateSourceStatus：标记每条是否有更新

导入策略 importSelect()：
1. 遍历选中项，根据 keepName/keepGroup/keepEnable 保留本地同名/同组/启用属性

### 6.12 BookSource 批量 URL 导入

ImportBookSourceViewModel 支持一种特殊的批量 URL 导入格式：

    { "sourceUrls": ["https://url1", "https://url2"] }

当 JSON 对象包含 sourceUrls 字段时，会逐个 URL 调用 importSourceUrl() 下载并解析。RssSource 也支持类似格式（通过 jsonPath 读取 $.sourceUrls）。

源码：ImportBookSourceViewModel.kt L134-L148
